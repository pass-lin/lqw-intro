让资源决定成本，
不决定能力

大模型的推理开销主要在三处：模型有多大、一次预测要跑多少次前向、状态要占多少显存。我在每一处做压缩，并处理压缩之后暴露出来的失效。

一亿 token 的前缀之后，基线数值溢出，SANE 仍达 33.46 到 35.56，短上下文无损。36M 的参数在长程预测上追平 1B。7B 的模型在零样本数学推理上超过 72B 的基线。

只要还有一处成本落在能力上，这个愿就没有做完。

01 研究

三份推理开销

推理的开销可以拆成三项：参数、前向次数、状态显存。三篇论文各压一项。压缩都有前提，前提不成立时，省下来的开销会以另一种形式回来：更多次搜索、更长的取回路径，或者数值溢出。

01 显存 · 状态压到 O(1)

一亿 token 的上下文

在一亿 token 的长度上，注意力的计算量已经不可接受，而循环结构的状态大小与序列长度无关。超长上下文下循环几乎是唯一的选择，代价是状态本身就是全部记忆。把 RWKV-7 推到一亿 token 会看到一种稳定的失效形态：稀疏底架上出现局部范数升高。衰减让弱更新的通道保持很小，不均匀的注入让少数通道累积到极端值。SANE 在 chunk 边界做逐头的自适应 tanh 压缩，压异常值，保留低幅背景，不破坏 chunk 内的并行。

安全窗只有 3 到 5。窗口左边伤短上下文，右边数值稳定但推理归零。

02 前向次数 · 一次出整段

并行解码的配套偏置

非自回归预测一次产出整个区间，H 步解码压成 1 次前向。并行解码本身快，难点是配套的归纳偏置。循环结构带来时序上的偏置，参数量与序列长度无关。两者直接结合会出问题：预测区没有观测，状态靠 placeholder 推进，历史沿着逐步转移被衰减。逐层检查显示多数层的状态注入范数下降，转移矩阵范数基本不变。HART 让 attention 与 RWKV 交替，给预测位置一条直接取回历史的路径。

循环结构承担建模，attention 补的是取回路径。代价是架构里多出 attention 块。

36M 参数 · 长程 MASE 0.752 对 1B 的 0.754 · 中长程优于纯 RWKV

03 参数 · 先蒸馏，再搜索

用搜索换模型规模

训练时的一条路是蒸馏，把大模型的解题能力压进小模型，成本落在训练阶段（ICIC 2024）。CMCTS 把压缩放到推理时，不训练：无训练的模型在树搜索里会反复生成同几条续写，搜索预算花在同质状态上。CMCTS 在扩展阶段把动作限制在四类，在模拟阶段用偏序规则和过程奖励模型筛掉走不通的转移。

单次前向的模型小了十倍，代价是推理阶段要跑更多次搜索。这份开销从参数挪到了测试时，采样次数没有上限。

arXiv:2608.22354 · 2026 长上下文 Delta-Rule

SANE: State Anomaly Neutralization for Stable Extreme-Context Delta-Rule Models

Qingwen Lin, Boyan Xu, Xiao Liu, Zhifeng Hao, Ruichu Cai

一亿 token 时注意力已经算不起，循环是唯一的选择。失效集中在少数通道上，压住那几条通道，一亿 token 之后仍能推理。

循环结构的状态大小与序列长度无关，注意力的计算量随长度增长。在超长上下文这个量级上，这一差别决定可行性。Delta-Rule 模型把历史压进一个固定大小的状态，状态本身就是全部记忆。把 RWKV-7 推到一亿 token 会看到一种稳定的失效形态：稀疏底架上出现局部范数升高。衰减让弱更新的通道保持很小，不均匀的注入让少数通道累积到极端值。SANE 在 chunk 边界做逐头的自适应 tanh 压缩，压异常值，保留低幅背景，不破坏 chunk 内的并行。

ICLR 2027 · arXiv:2610.12883 时序基础模型 RWKV

HART: Hybrid Attention-RWKV Time series Foundation Model

Qingwen Lin, Boyan Xu, Shifeng Xie, Zhifeng Hao, Keli Zhang, Ruichu Cai

并行解码本身快，难点是配套的归纳偏置。纯 RWKV-7 在预测区被衰减，交替之后 36M 追平 1B。

非自回归预测一次出整段，循环状态要穿过整个预测区，期间没有新观测。RWKV-7 在这个设定下退化：逐层检查显示，多数层的状态注入范数下降，转移矩阵范数基本不变，衰减来自逐步转移。HART 保留循环块承担时序建模，间插 attention 块，让预测位置可以直接取回历史。

Applied Intelligence 56(13) · 2026 大模型推理 树搜索

CMCTS: A Constrained Monte Carlo Tree Search Framework for Mathematical Reasoning in Large Language Model

Qingwen Lin, Boyan Xu, Guimin Hu, Zijian Li, Zhifeng Hao, Keli Zhang, Ruichu Cai

把搜索限制在一个有限动作集里，7B 的模型在零样本下超过了 72B 的基线。

多步数学推理适合树搜索，但无约束的扩展会反复找回同样的状态，无约束的模拟会接受那些单步看着合理、整体却是错的转移。CMCTS 在扩展阶段用有限动作集恢复状态多样性，在模拟阶段用偏序规则和过程奖励模型过滤不合理的转移。三个组件逐一消融，去掉任何一个都会掉点。

ICIC 2024 · LNCS 弱监督 蒸馏

From Large to Tiny: Distilling and Refining Mathematical Expertise for Math Word Problems with Weakly Supervision

Qingwen Lin, Boyan Xu, Zhengting Huang, Ruichu Cai

弱监督只有答案、没有方程，规则搜索补出来的方程能算出正确的数，语义却对不上题面。先让大模型把方程写对，小模型就够用了。

人工标注「问题-方程」对成本高，弱监督设定只用最终答案作监督信号，现有方法靠随机游走、束搜索等规则搜索补方程，搜出来的方程只保证算得对，语义对不上也没有约束。FLTT 分两段处理：蒸馏阶段用多轮对话让 ChatGPT 生成并自校正方程，再做格式检查与结果检查；精炼阶段用已成功的样本微调一个中间模型，对搜索失败的数据做迭代复搜。两段数据合起来训练 UniLM 或 T5 这类小模型。

03 关于

林庆文

2001 年生，广东工业大学计算机学院博士研究生。研究大模型的推理开销：压参数、压前向次数、压状态显存，并处理压完之后落在别处的成本。工作覆盖语言模型与时序基础模型。

四篇论文对应四次取舍：把状态压到 O(1)，看一亿 token 之后还剩多少能力；用一次前向替代 H 步解码；用小模型加搜索替代更大的模型；把大模型写好的方程蒸馏给小模型。
